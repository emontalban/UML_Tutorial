# 📦 UML Exercise Repository

Este repositorio contiene una colección de ejercicios prácticos de UML diseñados para reforzar el modelado de sistemas.

El objetivo es practicar cómo pasar de requisitos de un sistema a diagramas UML estructurados y comprensibles.

---

# 🧠 Contenido del proyecto

Este repositorio está dividido en dos partes:

## 📚 Wiki (Teoría UML)

La Wiki contiene la parte teórica del aprendizaje UML:

- Introducción a UML
- Diagramas estructurales
- Diagramas de comportamiento
- Conceptos fundamentales
- Notación UML

👉 Accede aquí:   [Tutorial Uml](https://github.com/emontalban/UML_Tutorial/wiki)


---

## 🧪 Ejercicios UML (Práctica)

El repositorio contiene ejercicios prácticos donde se aplican los conceptos UML.

Cada ejercicio incluye:

- Enunciado del problema
- Diagrama UML
- Explicación del modelo
